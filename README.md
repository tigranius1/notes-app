# Notes App

Простое веб-приложение для создания, просмотра, редактирования и удаления заметок на Django.

## Технологии

- Django 5.0
- SQLite (база данных по умолчанию)
- Bootstrap 5 (через CDN)

## Функционал

- Список заметок
- Создание заметки (заголовок + текст + теги)
- Просмотр отдельной заметки
- Редактирование заметки
- Удаление заметки с подтверждением
- Поиск по заголовку и тексту
- Теги: many-to-many, фильтрация по тегу, автосоздание новых тегов

## Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/tigranius1/notes-app.git
cd notes-app

# Установить зависимости
pip install -r requirements.txt

# Применить миграции
python manage.py migrate

# Запустить сервер
python manage.py runserver
